# Legalacts (ЦУБИПСА)

**Legalacts** е комплексна система за управление и публичен достъп до съдебни актове на българските съдилища. Системата осигурява централизиран интерфейс за публикуване, търсене и преглед на съдебни решения, напълно интегриран с европейските стандарти за идентификация на съдебната практика.

## Централен уеб базиран интерфейс (ЦУБИПСА)

Основният модул **Legalacts.Web** представлява **Централният уеб базиран интерфейс за публикуване на съдебни актове (ЦУБИПСА)**. Той позволява на гражданите и юридическите лица свободен достъп до съдебната практика при спазване на изискванията за защита на личните данни.

### Ключови функционалности:
- **Публичен достъп**: Разглеждане и търсене в реално време без необходимост от регистрация.
- **Анонимизация**: Автоматизирано представяне на актове със заличени лични данни.
- **Пълнотекстово търсене**: Високоефективна търсачка (базирана на Lucene), позволяваща филтриране по ключови думи, съд, вид дело, номер, година и съдия.
- **Интеграция с външни системи**: Възможност за масов импорт на данни от вътрешни съдебни системи.

## ECLI Интеграция

Системата напълно поддържа **European Case Law Identifier (ECLI)** – единен европейски стандарт за идентификация на съдебни актове.

### Технически характеристики на ECLI модула:
- **Автоматично генериране**: Генериране на уникални ECLI кодове (напр. `ECLI:BG:COURT:YYYY:NNNN.NNNNN`) съгласно препоръките на ЕС.
- **Интеграция с европейската търсачка**: Директна връзка с [European e-Justice Portal](https://e-justice.europa.eu/).
- **Dynamic robots.txt**: Специализирана конфигурация на `robots.txt`, която разрешава достъп на европейския краулер (**DG_JUSTICE_CRAWLER**) до метаданните.
- **Sitemap Generation**: Динамично генериране на XML Sitemaps за индексиране на актовете от европейската търсачка.

## Технологичен стек
- **Framework**: .NET Framework 4.6.1+
- **Database**: MS SQL Server 2012+
- **Web**: ASP.NET MVC 5, Web API 2
- **Architecture**: Domain-Driven Design (DDD) patterns, Repository Pattern
- **Зависимости**: 
  - **Ninject**: Внедряване на зависимости (Dependency Injection)
  - **NLog**: Инфраструктура за логване
  - **Lucene.Net**: Търсачка за пълнотекстово търсене
  - **PagedList.Mvc**: Пагинация за потребителския интерфейс

## Структура на проекта
- `Legalacts.Web`: Основно уеб приложение с публичен достъп (ЦУБИПСА).
- `Legalacts.ECLI.Integrator`: API услуга за ECLI метаданни и интеграция с европейския краулер.
- `Legalacts.ECLI.Converter`: Фонова услуга за конвертиране на актове към формати, съвместими с ECLI.
- `Legalacts.Model`: Домейн модели и слой за достъп до данни (Entity Framework).
- `Legalacts.Database`: SQL схема и скриптове за обновяване.

## Информация за проекта

Проектът се реализира в рамките на инициативата **„Обновени информационни системи за по-добро обслужване. Нормативна уредба на електронното правосъдие“**.

- **Обособена позиция № 5**: „Създаване на централен уеб базиран интерфейс за публикуване на съдебните актове“.

**Финансиране:**
- Осъществено с финансовата подкрепа на **Оперативна програма „Административен капацитет“**, съфинансирана от **Европейския социален фонд** и от държавния бюджет на Република България.
- Въвеждането на **Европейския идентификатор на съдебната практика (ECLI)** е подкрепено от **Програма „Правосъдие“** на Европейския съюз (2014-2020).
